# FinControl
Projeto de controle financeiro feito com backend em Python

O projeto consiste em um site que eu utilizo para uso pessoal, eu consigo ter uma noção de quanto dinheiro está entrando e quanto está saindo,
em que eu estou gastando meu dinheiro e ele tambem exibe um gráfico de pizza das despesas e exibe um percentual com uma regra que eu tento seguir:
50% gasto em necessidades, 30% desejos e 20% em investimentos;
Todos os dados inseridos são armazenados no próprio computador.

Linguagens utilizadas
Frontend: HTML, CSS, JavaScript;
Backend: Python

Foi também criado um JSON para que o site fique totalmente funcional em um dispositivo móvel e que funcionasse como um PWA Offline.

Não foi possível utilizar esta versão no celular, não consegui colocar essa versão do app para que fique sempre no ar sem o computador estar ligado.
